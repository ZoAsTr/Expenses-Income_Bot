# Telegram-бот учёта доходов и расходов

## Возможности
- Доходы и расходы с категориями
- Быстрый ввод суммы и описания
- Статистика по периодам
- Лимиты по категориям
- Курсы валют и экспорт отчётов в Excel
- Напоминания и периодические отчёты

## Локальный запуск
1. Установите Python 3.11 или 3.12.
2. Создайте виртуальное окружение: `python -m venv .venv`
3. Активируйте его и установите зависимости: `pip install -r requirements.txt`
4. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN`.
5. Запустите из любой директории: `python /путь/к/Expenses_Income_Bot/main.py`

База `expense_bot.db` создаётся рядом с `config.py`, а не в текущей рабочей директории.
Папка `exports/` также находится рядом с проектом.

## Важно перед публикацией
- Не коммитьте `.env`, токен, `expense_bot.db`, виртуальное окружение и экспортированные Excel-файлы.
- Если токен когда-либо попал в публичный репозиторий, отзовите его через BotFather и создайте новый.
- Для сервера используйте отдельную копию `.env`; не загружайте её в GitHub.
- Сделайте резервную копию `expense_bot.db` перед обновлением кода.
